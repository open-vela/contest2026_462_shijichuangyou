## 关于演示视频

**视频尚未录制。** 原因是本作品的全部硬件行为（面板断电熄屏、触摸唤醒、加速度计摇动、
RTC 掉电保时）**从未在真机上验证过**——串口权限未取得，板子未烧录。

因此这里**不放**用电脑模拟画面冒充真机的视频。作品的诚实边界比一段好看但失真的演示更重要：
`docs/OPENVELA_USAGE.md` 与 README 第六节都如实记录了「AI 与多媒体未落地」「真机全部 NOT_RUN」。

`拾迹创游-演示视频脚本.md` 是按**真机已烧录**编写可直接照读的录制脚本，并在文末列出录制时的
诚实性约束（不伪造真机画面、不夸大熄屏、不谎称 AI、未验证的功能不演示）。

## 如何重新生成这些文档

除视频外的四份文件均由脚本生成，可复现：

```bash
# 依赖：reportlab、python-docx、python-pptx、fontTools
python3 tools/generate_submission_docs.py
```

脚本会从系统的 `uming.ttc` 中抽取中文字体面（reportlab 不支持 .ttc 与 CFF 轮廓）。
文档中的所有数字都取自本仓实测输出，脚本内不含人工编造的数据。
